UniGen API

One unified endpoint for AI agents to generate images, video, and audio from any provider. No API keys. No accounts. Just USDC.

Base URL

https://unigen-api.ai/v1

Endpoints

Endpoint Method Description
/v1/generate POST Generate media (image, video, audio). Specify provider and model. UniGen passes through.
/v1/estimate POST Pre-generation estimate: price, estimated time, success rate.
/v1/capabilities GET List supported providers and models.
/v1/pricing GET Current pricing table per provider and model.
/v1/status GET Service operational status per provider.
/v1/balance GET Check USDC balance for a wallet address.

Payment

USDC via x402 protocol. No API keys. No accounts. Pay per request.
